Why this closes the problem for good, not just at the widths tested: because the panel's width is a function of the current viewport (vw) rather than a fixed number, its right edge is always a fixed proportional distance from the window edge — there is no width at or above 1024px where it can run out of room, since it never claims more room than a fraction of what actually exists. This replaces Option A/B's fixed-540px/480px tradeoff entirely: no anchor-direction decision needed, because the panel can no longer be wider than the space it has.
